# Обновление0.5.3

Обновите лаунчер через кнопку «Обновить лаунчер». Закройте игру, выберите русский перевод и обновите пакет до0.2.6, затем запустите игру самостоятельно.

Исправляется подтверждённый журналом сбой создания шрифта (`shader` равен null) и ложная диагностика недостающих букв. Надпись счётчика игроков сокращена до «Игроков:». Все доработки0.5.2 сохранены.

Игра не перезапускалась при подготовке. Следующая проверка в игре: те же реплики с !/?/запятыми и таблички. Новый результат рендера ещё не подтверждён. Старые журналы0.2.5 содержат ложные предупреждения об отсутствии многих букв; после обновления оценивайте новый журнал.
