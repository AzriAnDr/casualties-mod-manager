# Обновление 0.5.4

1. Обновите лаунчер штатной кнопкой или скачайте EXE из релиза v0.5.4.
2. Закройте игру. Выберите «Русский перевод» и нажмите «Установить / обновить», чтобы установить 0.2.7.
3. «Обновления модулей» проверяет отдельный канал пакетов. После проверки выбранный пакет устанавливается обычной кнопкой с просмотром файлов. Отсутствие сети оставляет доступными встроенные пакеты; более новый установленный модуль не понижается.

Модули можно обновлять без замены лаунчера. Together берётся с GitHub автора; русский перевод, справочник и BepInEx — из закреплённого каталога `modules-stable/modules.json` этого проекта. URL, SHA-256, размер и совместимость с игрой проверяются. Автоматической установки без просмотра нет.

## Публикация пакетов без новой версии EXE

Соберите новые пакеты, увеличив версию изменённого модуля. Выполните `publish_modules.py --russian ПУТЬ_RU_ZIP --russian-version ВЕРСИЯ --wiki ПУТЬ_WIKI_ZIP --wiki-version ВЕРСИЯ --game-version ВЕРСИЯ_ИГРЫ`. Неизменённый пакет передавайте без изменений. Скрипт не заменяет содержимое уже опубликованного ZIP с той же версией. Сначала публикуются ZIP, затем каталог. Служебный prerelease `modules-stable` не становится последним релизом лаунчера.

Кириллица для рукописных шрифтов создаётся из локально установленных игровых глифов во время игры. Игровые атласы и файлы шрифтов в раздачу не включены. Если конкретный шрифт нельзя безопасно дополнить, используется прежний рабочий вариант.

Мод, полностью удалённый вручную, исчезает из списка при нажатии «Обновить» у папки игры. Манифест сохраняется до следующей установки/удаления для истории владения; он не означает, что мод установлен. Если остались ресурсы, отображается неполная установка. Изменённые файлы менеджер не удаляет.
