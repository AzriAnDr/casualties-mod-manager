# Обновление0.5.8

Обновите лаунчер кнопкой «Обновить лаунчер» либо скачайте EXE релиза.

Закройте игру. В «Загрузках» включите «Показывать все ZIP», выберите готовый архив и нажмите «Установить выбранный ZIP». Для локального BepInEx-плагина менеджер покажет имя, версию, список DLL/ресурсов и предупреждение. После подтверждения мод появится в «Моих модах» как локальный под управлением.

Там его можно отключить или удалить вместе с ресурсами, записанными при установке. Для обновления выберите новый ZIP с тем же набором GUID. Совместимость и зависимости проверяйте у автора; каталог для локальной установки не нужен.

Если плагин с тем же GUID уже установлен вручную, удалите прежнюю копию через её карточку перед установкой. Менеджер не удаляет её автоматически.

Русский пакет0.2.12 не менялся.
