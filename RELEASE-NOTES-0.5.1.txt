Обновление для Casualties: Unknown 1.0.2 на базе стабильной 0.5.0.

- Русский перевод 0.2.4: свежий перевод сообщества, новые настройки и изменение способности «Стрелок»; сохранены исправления шрифтов.
- Фильтр по тегам: выбор нескольких, поиск по списку и сброс. Совпадение с любым выбранным тегом вместе с другими фильтрами.
- Character Unlock убран из встроенных предложений. Старую установку можно отключить/удалить; автоматически файлы не удаляются.
- Справочник 0.2.1 помечен WIP.
- Исправлены ограничения загрузок, распаковка ZIP и откат; обновлятор закреплён за официальным репозиторием и версией релиза.

Как обновиться:
1. В 0.5.0 нажмите «Обновить лаунчер» и подтвердите обновление до 0.5.1. Либо скачайте Casualties-ModManager.exe из этого релиза.
2. Закройте игру. В новом менеджере выберите «Русский перевод» и установите/обновите встроенный пакет до 0.2.4. Обновление лаунчера само по себе не заменяет уже установленные плагины.
3. При желании отдельно обновите справочник до 0.2.1 (WIP).

Русификатор поддерживает игру 1.0.2. Бепинекс 5.4.23.5 встроен. Настройки и открытия справочника сохраняются.
Экспериментальная Nexus API-интеграция из 0.6.0 не включена: Nexus через сайт с подхватом ZIP, GitHub — загрузка внутри менеджера.
