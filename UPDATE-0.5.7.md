# Обновление0.5.7

Нажмите «Обновить лаунчер» или скачайте новый EXE из релиза.

Закройте игру, выберите ручной плагин в «Моих модах» и нажмите «Удалить». Проверьте список DLL и подтвердите. Менеджер сохранит резервную копию; путь будет указан в истории действий. При изменении DLL между сканированием и удалением обновите список и повторите.

Для ручной установки удаляются только показанные DLL. Папки ресурсов, включая CustomSprites, остаются на месте. Для мода, установленного менеджером, используется его полный сохранённый список файлов.

Русский пакет0.2.12 не менялся; повторно устанавливать его из-за этого обновления не требуется.
