# Обновление0.5.5

В текущем менеджере нажмите «Обновить лаунчер» и подтвердите0.5.5 либо скачайте EXE из релиза. Разделители таблиц теперь одинаковы в строках и пустой области.

Русификатор0.2.10 включён в комплект. Чтобы обновить установленный перевод, закройте игру, выберите «Русский перевод» и нажмите «Установить / обновить». Обновление EXE не заменяет установленные моды автоматически.

Для последующих пакетов по-прежнему доступна кнопка «Обновления модулей» без новой версии EXE.

Официальная сборка может переиспользовать опубликованные пакеты: `build.py ... --russian-package packages/Russian-0.2.10.zip --wiki-package ПУТЬ_ОПУБЛИКОВАННОГО_WIKI_ZIP`. Без этих аргументов выполняется обычная сборка пакетов из исходников.
