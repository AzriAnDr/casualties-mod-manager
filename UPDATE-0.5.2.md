# Обновление 0.5.2 — компоновка каталога

Обновление на базе 0.5.1. Доступно через GitHub Releases и кнопку «Обновить лаунчер».

Вкладка «Каталог»: компактные поиск и фильтры сверху, основная высота отдана списку модов и описанию. Название и автор показаны отдельно, ширину списка и описания можно менять разделителем. Четыре действия размещены сеткой 2×2. Фильтры и загрузки работают как прежде.

После успешного запуска обновлённого менеджера старая резервная копия его EXE (`.bak`) удаляется автоматически. При неудачном запуске копия остаётся для восстановления. Очистка проверяет путь, имя и версию копии; не удаляет неизвестные, повреждённые, такие же или более новые EXE. Резервные копии модов не затрагиваются.

Русификатор 0.2.5 для игры 1.0.2, справочник 0.2.1 WIP и BepInEx 5.4.23.5 встроены.

## Шрифты и Together

Шрифтовая обработка переработана: собственный TMP-набор из встроенного Retro Gaming, согласованные кириллица/латиница/пунктуация, выбор до построения таблиц материалов. Поздняя перезапись материала мирового текста удалена. Исходные общие шрифтовые атласы игры не редактируются; внешние шрифты и правка файлов игры не нужны.

Для известных игровых реплик Together используются одинаковые пары английских/русских строк по ключу и индексу реплики. Исходящие известные русские реплики приводятся к английскому представлению; принимающий русификатор показывает соответствующий русский текст. Ручной чат не переводится. Незнакомые, изменённые или неоднозначные фразы сохраняются без угадывания.

Всем игрокам с русификатором нужно обновить пакет до 0.2.5. Английскому клиенту без русификатора известные реплики от обновлённого русского отправителя приходят по-английски. Формат сетевых пакетов не меняется.

Шрифтовой рендеринг и обмен репликами ещё нужно проверить в самой игре на двух клиентах. Сборка подготавливалась без запуска игры и окна менеджера; автоматические проверки не заменяют эту проверку.


## Версия игры для модов

Колонка «Версия игры» появилась во вкладках «Мои моды» и «Каталог». Для собственных пакетов учитывается установленная версия. Для сторонних модов показываются явные поля совместимости из каталога, если они есть; «Не указана» означает, что надёжных данных в базе нет. Версия мода и версия BepInEx не используются как версия игры. Метаданные нового релиза не приписываются старой установленной версии.

Для проверки закройте игру, откройте новую сборку и обновите «Русский перевод» до0.2.5. На всех русских клиентах Together нужен этот пакет. Затем сравните те же таблички и реплики в русско-английской паре клиентов. Ручной чат должен остаться исходным.


Исправлено ложное уведомление об обновлении при совпадении актуального DLL по SHA-256, даже если автор использовал разные номера версии архива, сборки и BepInPlugin.
