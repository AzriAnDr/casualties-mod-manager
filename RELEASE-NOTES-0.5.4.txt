Casualties Mod Manager 0.5.4 / русский модуль 0.2.7

• Независимые обновления русского перевода, справочника и BepInEx через каталог пакетов: кнопка «Обновления модулей», затем «Установить / обновить». Together обновляется из репозитория автора. Обновлять EXE для новых пакетов больше не требуется.
• Тёмные полосы прокрутки и углы заголовков списков: белые квадраты убраны.
• «Загрузки» по умолчанию скрывают неизвестные ZIP. Показать их можно флажком «Показывать все ZIP». Принадлежность игры не угадывается по одному имени архива.
• Исправлена лишняя папка plugins при установке ZIP с такой обёрткой. При обновлении удаляются прежние управляемые файлы, отсутствующие в новом пакете; чужие и изменённые файлы защищены.
• Сокращены пути резервных копий: удаление модов с большим количеством ресурсов больше не удлиняет их пути зеркальным копированием папок.
• Полностью удалённый вручную мод исчезает из «Моих модов» при обновлении списка; неполная установка помечается отдельно. Переустановка восстанавливает отсутствующие файлы, удаление допускает уже отсутствующие файлы.
• Для трёх оригинальных рукописных шрифтов создаётся кириллическое дополнение во время игры. Оригинальные латинские символы сохраняются; новые русские буквы — наша адаптация, а не рисунки автора оригинального шрифта. При неподдерживаемом атласе остаётся безопасный пиксельный шрифт.

Закройте игру перед изменением модов. Обновление EXE не обновляет установленные плагины автоматически. После запуска 0.5.4 отдельно обновите русский модуль до 0.2.7.
Игра и окно менеджера при подготовке не запускались; проверка шрифтов на GPU и совместная игра требуют пользовательского теста.
