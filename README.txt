# Обновление 0.5.1 на базе 0.5.0

Для Casualties: Unknown 1.0.2. Закройте игру, откройте новый Casualties-ModManager-0.5.1.exe, выберите «Русский перевод» и нажмите установку/обновление встроенного пакета. Проверьте список файлов перед подтверждением. Старый0.5.0 не устанавливает перевод на игру1.0.2.

- Русификатор0.2.4: обновлённый перевод сообщества, новые настройки и описание Marksman; шрифтовые исправления сохранены.
- Каталог: «Теги…», поиск по списку тегов, выбор нескольких и сброс. Совпадение с любым выбранным тегом, одновременно с остальными фильтрами.
- Character Unlock больше не предлагается как встроенный мод. Старую установку можно отключить/удалить; автоматически её файлы не удаляются. В общем каталоге мод остаётся сторонним.
- Справочник0.2.1 помечен WIP в менеджере и игре; открытия сохраняются.
- Сохранены исправления загрузчика/обновлятора. Экспериментального подключения аккаунта Nexus нет: скачивание Nexus через сайт с подхватом ZIP, GitHub — непосредственно в менеджере, как в0.5.0.

Сборка и проверки выполнены без запуска игры или окна менеджера. Игровая проверка новой версии ещё нужна. Обновление распространяется через GitHub Releases и кнопку «Обновить лаунчер» в 0.5.0. После обновления лаунчера отдельно обновите русский перевод во вкладке «Мои моды».
