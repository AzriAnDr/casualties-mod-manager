Casualties Mod Manager 0.5.4 / русский перевод 0.2.7

Скачать: https://github.com/AzriAnDr/casualties-mod-manager/releases/tag/v0.5.4
Закройте игру перед установкой модов. После обновления EXE отдельно обновите русский перевод во вкладке «Мои моды».

Независимые обновления: «Обновления модулей», затем «Установить / обновить» для выбранного модуля. Русский перевод, справочник и BepInEx проверяются по отдельному каталогу пакетов; Together — по репозиторию автора. Замена лаунчера при этом не требуется.

Загрузки показывают подходящие архивы; неизвестные доступны через «Показывать все ZIP». Для Nexus скачивание производится через сайт, для GitHub — внутри менеджера.

Исправлены вложенная папка plugins, длинные пути резервных копий и оставшиеся записи после ручного удаления модов. Установка стороннего мода не удаляет другие моды. Изменённые и чужие файлы защищены.
