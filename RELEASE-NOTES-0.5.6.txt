Лаунчер0.5.6 и русский перевод0.2.12 для игры1.0.2.

— «Мои моды» видит вручную установленные BepInEx-плагины, включая переименованные DLL и версии, отсутствующие в каталоге. Читает декларации из метаданных без запуска кода модов.
— Неоднозначные GUID не связываются с каталогом автоматически. Afterdark0.2.3 отображается отдельно от двух старых записей каталога с общим GUID.
— Полностью отсутствующая старая установка больше не скрывает реально установленную DLL. Ресурсы CustomSprites не принимаются под управление автоматически.
— Для ZIP, выбранного вручную, несовпадение SHA-256 открывает предварительный просмотр другого архива, если внутри есть ожидаемая DLL и GUID. Подлинность такого архива явно не подтверждена; установка требует отдельного подтверждения списка файлов. Автоматические скачивания сохраняют строгую проверку хеша.
— Для другого архива хранится фактическая версия плагина вместо старой версии каталога. По одному GUID обновление не объявляется.
— Переведены Join / Joining / Ready / Ready up в выборе персонажа Together. Счётчик и условия доступности сохранены. Шрифты не изменены.

Русификатор обновляется отдельно через «Обновления модулей». Обновление EXE само не заменяет установленные моды. Перед изменением модов закройте игру.
