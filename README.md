# Casualties Mod Manager

Лаунчер **0.5.4**, актуальный русский модуль **0.2.9** (обновляется отдельно): [инструкция](UPDATE-0.5.4.md), [проверки и ограничения](QA-RESULTS-0.5.4.txt).

Менеджер модов для **Casualties: Unknown 1.0.2**, Windows x64.

[Скачать лаунчер 0.5.4](https://github.com/AzriAnDr/casualties-mod-manager/releases/download/v0.5.4/Casualties-ModManager.exe) · [Все выпуски](https://github.com/AzriAnDr/casualties-mod-manager/releases)

Для друзей достаточно одного EXE: русификатор **0.2.7**, справочник **0.2.1 (WIP)** и официальный BepInEx **5.4.23.5** встроены. Together загружается с GitHub автора.

## Обновление с 0.5.0 / 0.5.1

1. Нажмите «Обновить лаунчер» и подтвердите переход на 0.5.4 либо скачайте EXE по ссылке выше.
2. Закройте игру, выберите «Русский перевод» в новом менеджере и обновите встроенный пакет до 0.2.7. Обновление лаунчера не заменяет плагины автоматически.
3. При желании отдельно обновите справочник до 0.2.1 (WIP).

Подробнее: [инструкция](UPDATE-0.5.4.md), [изменения](RELEASE-NOTES-0.5.4.txt), [проверки](QA-RESULTS-0.5.4.txt).

## Каталог и управление

Каталог Metadata-generator: поиск по названию/автору/описанию, реальные теги Nexus, фильтры установленных модов, обновлений и 18+. В офлайн-снимке 628 записей и 79 тегов. Несколько выбранных тегов работают по условию «любой выбранный» совместно с остальными фильтрами. Выбор сохраняется при обновлении каталога.

Nexus ZIP скачивается на сайте и подхватывается во вкладке «Загрузки»; GitHub ZIP при явной ссылке на репозиторий можно скачивать внутри менеджера. Экспериментальная интеграция Nexus API из 0.6.0 не включена.

Установка/обновление показывают список файлов, сохраняют манифесты и резервные копии. Модифицированные или чужие файлы защищены от перезаписи. Мутации при запущенной игре запрещены. Загрузки и распаковка имеют ограничения размера, времени и путей; обновлятор закреплён за этим репозиторием и версией релиза.

Character Unlock больше не предлагается как встроенный мод; прежнюю установку можно отключить/удалить. Файлы автоматически не удаляются. В общем каталоге он остаётся сторонним модом.

## Источники и проверки

Перевод сообщества: [Orsoniks/scavgame-locale](https://github.com/Orsoniks/scavgame-locale), RU 1.0.2 commit f88251a. Полное авторство и лицензии в assets; локальная адаптация описана в [отчёте](assets/LOCALE-UPDATE-0.2.4.txt). Все 5944 поля сверены с языковыми файлами игры 1.0.2.

Метаданные: [Metadata-generator](https://github.com/jimmyking9999999/Metadata-generator), MIT. Они помогают найти моды, но не гарантируют совместимость с текущей игрой или Together.

Результаты проверки конкретной сборки Defender указаны в QA-RESULTS-0.5.4.txt. Прежний вердикт Microsoft Not malware относится только к EXE0.5.0. Отключать защиту и добавлять исключения не требуется.

Игра и окно менеджера при подготовке0.5.4 не запускались. Визуальная и многопользовательская проверка в игре ещё нужна. Справочник находится в разработке.

## Сборка

`python build.py --game ПАПКА_ИГРЫ --sdk ПУТЬ_DOTNET --work ПАПКА_СБОРКИ`

Нужны Windows .NET Framework compiler и .NET SDK. Игровые DLL в репозиторий не включены; ссылки берутся из установленной игры. Сборочный скрипт не запускает игру или менеджер. Исходники BepInEx приложены отдельным ZIP в релизе.

Начиная с 0.5.4, встроенные модули обновляются через отдельный каталог пакетов без новой версии EXE. См. [инструкцию](UPDATE-0.5.4.md). В «Загрузках» неизвестные ZIP скрыты, пока не включён показ всех архивов.

## Отдельный пакет русификатора0.2.8

Закройте игру. В лаунчере0.5.4 нажмите «Обновления модулей», выберите русский перевод и установите0.2.8. EXE по-прежнему содержит0.2.7 как офлайн-комплект; свежий пакет берётся из отдельного каталога. См. [изменения0.2.8](RELEASE-NOTES-RU-0.2.8.txt), [проверки](QA-RU-0.2.8.txt).

Сборка одного модуля без EXE: `python build_modules.py --module russian --game ПАПКА_ИГРЫ --sdk ПУТЬ_DOTNET --work ПАПКА_СБОРКИ`. Публикация — `publish_modules.py`; неизменённый пакет справочника нужно взять из существующего канала, сохранив его байты.

Актуальный отдельный пакет: [русский0.2.9](RELEASE-NOTES-RU-0.2.9.txt), [проверки и ограничения](QA-RU-0.2.9.txt). Обновите его через «Обновления модулей» в0.5.4. Старые разделы0.2.8 описывают предыдущий пакет.
