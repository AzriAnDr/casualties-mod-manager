# Casualties Mod Manager

Менеджер модов для **Casualties: Unknown1.0.2**, Windows x64. Лаунчер **0.5.13**, русский перевод **0.2.12**.

[Скачать лаунчер](https://github.com/AzriAnDr/casualties-mod-manager/releases/download/v0.5.13/Casualties-ModManager.exe) · [Изменения](RELEASE-NOTES-0.5.13.txt) · [Обновление](UPDATE-0.5.13.md) · [Проверки](QA-RESULTS-0.5.13.txt)

Для друзей достаточно одного EXE: русификатор0.2.12, справочник0.2.1(WIP) и официальный BepInEx5.4.23.5 встроены. Together загружается с GitHub автора. Кнопка «Обновления модулей» получает новые пакеты без замены EXE. Изменение модов требует закрытой игры; обновление EXE само не заменяет установленные моды.

Каталог Metadata-generator: поиск по названию, автору и описанию, теги Nexus, фильтры установленных модов, обновлений и18+. Офлайн-снимок:628записей,79тегов. Несколько тегов работают по условию «любой выбранный».

Nexus ZIP скачивается на сайте и подхватывается в «Загрузках». Неизвестные ZIP скрыты до включения «Показывать все ZIP». Их можно установить как локальные BepInEx-моды после просмотра метаданных и списка файлов, без записи каталога. Для DLL в корне создаются короткие папки вида `Community/ScavSexMod-b7045b90`; полный GUID-идентификатор хранится в манифесте. Прежние длинные пути поддерживаются и сокращаются при следующем обновлении мода. GitHub ZIP при явной ссылке на репозиторий можно скачать внутри менеджера. Экспериментальная интеграция Nexus API из0.6.0 не включена.

«Мои моды» показывает также ручные BepInEx-плагины: метаданные читаются без выполнения их кода. При неоднозначном GUID связь с каталогом не назначается автоматически. Ресурсы вроде CustomSprites не считаются отдельными плагинами и автоматически не принимаются под управление. Ручную DLL можно удалить после просмотра конкретного списка файлов; резервная копия сохраняется, соседние ресурсы остаются.

Установка показывает список файлов и сохраняет резервные копии. Модифицированные и чужие файлы защищены от перезаписи. При ручном выборе другой версии ZIP несовпадение SHA-256 требует явного подтверждения непроверенного архива и ожидаемого GUID; автоматические скачивания проверяют хеш строго. Декларация GUID не гарантирует подлинность или совместимость.

Character Unlock не предлагается как встроенный мод. Справочник находится в разработке.

В «Истории действий» доступен отчёт для кооператива: версии и SHA-256 установленных DLL, хеш игры, отключённые/повторные копии и исторические версии из лога. Для причины отказа подключения сравните отчёты клиента и хоста; совпадение отпечатка не гарантирует совпадение ресурсов/настроек.

Интерфейс0.5.12 полностью переведён на WPF; пользователь подтвердил отсутствие мерцания. Старый движок файловых операций и манифесты сохранены. Together5.5.3 с отдельной CUCoreLib поддерживается: идентичная установленная общая библиотека сохраняется, новая учитывается отдельно от Together.

Начиная с0.5.13, старые резервные EXE менеджера автоматически очищаются после успешного первого отображения WPF-окна. Копии модов сохраняются.

## Источники и сборка

Перевод сообщества: [Orsoniks/scavgame-locale](https://github.com/Orsoniks/scavgame-locale), RU1.0.2 commit f88251a. Авторство и лицензии в assets; локальная адаптация описана в assets/LOCALE-UPDATE-0.2.4.txt. Метаданные каталога: [Metadata-generator](https://github.com/jimmyking9999999/Metadata-generator), MIT; совместимость проверяйте у авторов модов.

`python build.py --game ПАПКА_ИГРЫ --sdk ПУТЬ_DOTNET --work ПАПКА_СБОРКИ`

Нужны Windows .NET Framework compiler с установленными WPF-assemblies и .NET SDK. Сборка остаётся одним EXE. Для изолированной проверки GUI поддерживается `--output ПУТЬ_EXE`. Игровые DLL берутся из установленной игры и не распространяются в исходниках. Mono.Cecil0.11.6 (MIT) скачивается из официального NuGet с закреплёнными SHA-256 и встраивается в EXE вместе с лицензией. Исходники BepInEx приложены к релизу отдельно.

Для воспроизводимого включения опубликованных модулей используйте `--russian-package packages/Russian-0.2.12.zip --wiki-package ПУТЬ_ОПУБЛИКОВАННОГО_WIKI_ZIP`.

Игра при подготовке0.5.12 не запускалась; новый интерфейс проверен в окне на компьютере пользователя. Шрифты0.2.11 подтверждены пользователем;0.2.12 не меняет их. Новые подписи Together ещё требуют проверки в реальной сетевой сессии. Результаты Defender относятся только к проверенным файлам; старый ответ Microsoft Not malware относится к EXE0.5.0.
