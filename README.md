Переносимый менеджер модов для **Casualties: Unknown 1.0.1**, Windows x64.

## Скачать друзьям

[Скачать Casualties-ModManager.exe — 0.5.0](https://github.com/AzriAnDr/casualties-mod-manager/releases/download/v0.5.0/Casualties-ModManager.exe)
или открыть [историю выпусков](https://github.com/AzriAnDr/casualties-mod-manager/releases).

Достаточно передать один `Casualties-ModManager.exe`. Русификатор, справочник
и BepInEx встроены в него. Папки автора, исходники и отдельные ZIP рядом с EXE
не требуются. Для Together нужен интернет; архив скачивается с GitHub автора.

Лаунчер ищет игру по настройкам Steam, библиотекам `libraryfolders.vdf` и
манифесту приложения. Если игру найти не удалось, выберите её папку вручную.
Затем при закрытой игре установите BepInEx, нужные модули перевода и справочника,
а при необходимости — Together. Каждую операцию предваряет список файлов.

## Каталог и загрузки — версия 0.5.0

Вкладки разделены по задачам:

- **Мои моды**: встроенные модули и установленные из каталога моды,
  включение, отключение, удаление и переход к обновлению.
- **Каталог**: поиск по названию, автору и описанию, фильтры установленных
  модов и обновлений, описания и зависимости из базы сообщества.
- **Загрузки**: наблюдение за выбранной папкой браузерных ZIP-загрузок.
- **История действий**: результаты операций и пути резервных копий.

Каталог берётся из [Metadata-generator](https://github.com/jimmyking9999999/Metadata-generator).
В EXE есть офлайн-снимок на 613 записей; новые данные загружаются отдельно
с кешированием и HTTP-валидаторами. Источник метаданных и его MIT-лицензия
сохранены в `assets/CATALOG-LICENSE.txt`. Описания показываются на языке автора.

Для Nexus кнопка открывает страницу мода: скачайте ZIP обычным способом.
Лаунчер заметит завершённую загрузку и попробует сопоставить её с каталогом
по SHA-256. Установка никогда не начинается автоматически — сначала
показываются мод и точный список файлов. Неизвестный архив можно выбрать
через карточку нужного мода. API-ключ или Premium для просмотра каталога
не нужны; обхода правил скачивания Nexus нет.

Если в описании однозначно указан исходный GitHub-репозиторий автора,
доступна прямая загрузка ZIP последнего релиза с выбором файла.
Неоднозначные ссылки и имена репозиториев не угадываются.

Поддерживается импорт ZIP с плагинами в `BepInEx/plugins`, с сохранением
исходной структуры папок. Простые архивы с DLL и соседними ресурсами
устанавливаются в отдельную папку. Установщики EXE, 7z/RAR, пакеты с заменой
игровых файлов, патчеров или конфигурации этим импортом не поддерживаются.
Перед изменением закрывайте игру. Сохранения и пользовательские конфиги
не удаляются. Зависимости, кроме предлагаемого BepInEx, проверяйте у автора.

Версии установленных DLL сравниваются с соответствующими версиями DLL
в каталоге. Номер страницы/архива Nexus может отличаться и не используется
как версия DLL. Неизвестные версии и другие ветки помечаются отдельно.
Совпадение одного имени файла не считается доказательством установки.

Папка загрузок проверяется только по ZIP верхнего уровня: до 20 последних
файлов за проход. Незавершённые/открытые загрузки не импортируются. Для
старого или крупного архива используйте ручной выбор ZIP в каталоге.

## Обновления

Кнопка **«Обновить лаунчер»** проверяет этот репозиторий, показывает новый выпуск,
скачивает EXE и проверяет SHA-256. После подтверждения лаунчер закрывается,
его вспомогательный процесс заменяет EXE и запускает новую версию.
Предыдущий EXE остаётся рядом с расширением `.bak`.

Новый EXE содержит новые встроенные пакеты и актуальные ссылки каталога.
Моды, уже установленные в игру, обновляются отдельным действием:
это позволяет сначала закрыть игру и проверить изменения.

Для перехода со старых версий без кнопки обновления скачайте новый EXE один раз.
Установленные моды и их манифесты находятся в папке игры и сохраняются.

## Модули

- Русификатор игры и Together; включает названия 68 правил сервера.
- Внутриигровой справочник открытий, отдельный от русификатора.
- Casualties: Together — загрузка fullgame-релиза официального проекта.
- BepInEx 5.4.23.5 — встроенный загрузчик.
- SkipCharacterUnlock — страница автора и ручной импорт; совместимость с
  полной игрой и Together не подтверждена.

«Управлять модом…» регистрирует известные файлы ручной установки и создаёт их
копию. После этого менеджер может обновлять и удалять эти файлы.
Отключение, удаление, принятие под управление и обновление показывают
конкретный результат в истории. Изменённые чужим процессом файлы не заменяются
молча. Перед изменениями игру нужно закрыть.

## Состояние проверок

Сборка и файловые проверки выполняются отдельно от запуска игры.
Полная сессия с двумя игроками и отсутствие десинхронизаций не подтверждены.
Together 5.5.0 заявлен автором для fullgame 1.0; известные ошибки его патчей
на 1.0.1 менеджер не исправляет. Исправление табличек в русификаторе 0.2.3
собрано, но ещё требует проверки пользователем в игре.

## Сборка

Нужны Python 3, Windows .NET Framework, .NET SDK с netstandard2.1 и установленная
игра с BepInEx для ссылок компилятора. Игровые DLL в репозиторий не включены.

```powershell
python build.py --game "ПАПКА ИГРЫ" --sdk "ПУТЬ К dotnet.exe"
```

Версии встроенных пакетов читаются из результатов сборки и записываются
в каталог внутри EXE. Каталог доступен независимо от наличия игры на компьютере.

исправления не отправлялись в официальный репозиторий локализации.

Лицензии перевода, Together и BepInEx приложены в `assets`. Это неофициальная
программа, не связанная с разработчиками игры, Steam или Nexus Mods.
